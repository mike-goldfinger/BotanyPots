# BotanyPots – unofficial port to Minecraft 26.1

This is an **unofficial** port of [BotanyPots](https://github.com/Darkhax-Minecraft/BotanyPots) by Darkhax
from Minecraft 1.21.1 to **Minecraft 26.1.x** (26.1, 26.1.1, 26.1.2) for **NeoForge** and **Fabric**.
It is not affiliated with or supported by the original author. Please do not report issues with this port
to the upstream project; use the [issue tracker of this repository](https://github.com/mike-goldfinger/BotanyPots/issues) instead.

The mod is licensed under the [LGPL v2.1](LICENSE), like the original.

## Requirements

| | Version |
|---|---|
| Minecraft | 26.1 – 26.1.2 |
| Java | 25 |
| NeoForge | 26.1.0.1-beta or newer |
| Fabric Loader / Fabric API | 0.18.6+ / any 26.1 build |
| [Bookshelf](https://modrinth.com/mod/bookshelf-lib) | 26.1.2.15 or newer |
| [Prickle](https://modrinth.com/mod/prickle) | 26.1.2.6 or newer |
| [JEI](https://modrinth.com/mod/jei) | optional |

## Building

```sh
./gradlew build
```

The jars are written to `neoforge/build/libs` and `fabric/build/libs`. Gradle needs a full JDK 25.
The build uses Darkhax' [Minecraft Mod Conventions plugin](https://github.com/Darkhax-Minecraft/Minecraft-Mod-Conventions-Plugin)
(`net.darkhax.mmc`), which also regenerates `fabric.mod.json`, `neoforge.mods.toml` and the metadata block at the end
of this file on every build.

## Notable changes compared to 1.21.1

- Build migrated from the old `buildSrc` multiloader setup to the `net.darkhax.mmc` plugin used by the upstream 26.x mods.
- Since 1.21.2 the server no longer sends recipes to the client. BotanyPots needs its recipes on the client for rendering
  and JEI, so its recipe types are now synchronized explicitly (NeoForge `OnDatapackSyncEvent` / Fabric `RecipeSynchronization`).
- `ReloadableCache` / `SidedReloadableCache` were removed from Bookshelf and now live in
  `net.darkhax.botanypots.common.api.function`.
- Rendering was rewritten for the new render-state / `SubmitNodeCollector` pipeline. **The `DisplayRenderer` API changed:**
  the `MultiBufferSource` parameter was replaced by `SubmitNodeCollector` and `CameraRenderState`. Fluid rendering is
  implemented locally because Bookshelf 26.1 does not support it yet.
- Data files were converted to the 26.1 formats (plain/`#tag` ingredients, `neoforge:ingredient_type` for custom
  ingredients, renamed attribute ids, item model definitions in `assets/botanypots/items`, GUI slot sprites).
- `ItemStack` values in data (`new_soil`, `new_seed`, simple drop `result`) are parsed as `ItemStackTemplate`.
- The CraftTweaker and Simple Loot Viewer integrations were dropped because those mods are not available for 26.1.

## Growing trees

Trees are not part of Botany Pots itself but of the add-on [Botany Trees](https://github.com/Darkhax-Minecraft/BotanyTrees),
which has no 26.1 release. Because the recipe format is unchanged, its data works as a plain data pack with this port:
see [`datapacks/botany-trees`](datapacks/botany-trees) (vanilla trees incl. pale oak, drop into `<world>/datapacks`, `/reload`).

## Mystical Agriculture

Mystical Agriculture crops have no loot tables (their drops are computed in code), so in a Botany Pot they would only return
a seed. [`datapacks/botany-mystical`](datapacks/botany-mystical) adds explicit essence/seed drops for all 136 crops and
registers the Essence Farmlands as soils with per-tier growth and yield bonuses.

## Status

Ready-built jars are on the [Releases page](https://github.com/mike-goldfinger/BotanyPots/releases).

- **NeoForge:** play-tested since 2026-10-28 on a dedicated server (NeoForge 26.1.2.116, alongside AE2, Mystical Agriculture,
  Ex Deorum, Powah, JEI and others) and in single-player: crop rendering, GUI, JEI integration, hopper pots and data packs
  (including [`datapacks/botany-trees`](datapacks/botany-trees)) work. Versions 26.1.2.1–26.1.2.3 fixed a client crash on
  start, recipe sync when loading a world, and the pot item names.
- **Fabric:** compiles and a dedicated server loads all recipes without data errors, but it has **not been play-tested**.

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.botanypots', name: 'botanypots-neoforge-26.1.2', version: '26.1.2.3'
     // Fabric
     implementation group: 'net.darkhax.botanypots', name: 'botanypots-fabric-26.1.2', version: '26.1.2.3'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.botanypots', name: 'botanypots-common-26.1.2', version: '26.1.2.3'
}
```
